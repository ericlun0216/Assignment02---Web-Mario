# Cloudtop Run - Web Mario

軟體工程作業二  
學號：`109000105`

## 遊戲簡介

`Cloudtop Run` 是一款單關卡的瑪利歐風格平台遊戲，使用 Cocos Creator 2.4.8 製作，並輸出為 Web Desktop 版本部署到 Firebase Hosting。玩家需要穿越會捲動的丘陵關卡，撞擊問號磚、收集蘑菇、擊敗敵人，並在時間結束前抵達旗桿。

## 操作方式

| 動作 | 按鍵 |
| --- | --- |
| 左右移動 | `A` / `D` 或方向鍵左右鍵 |
| 跳躍 | `W`、`ArrowUp` 或 `Space` |
| 暫停 / 繼續 | `P` |
| 切換音效 | `M` 或畫面上的 `SOUND` 按鈕 |

規則說明：

- 從下方撞擊問號磚時，會掉出蘑菇或分數硬幣。
- 吃到蘑菇後會變大；若變大狀態下受到傷害，會回復成一般大小。
- 只有從上方踩到敵人頭頂，才算擊敗敵人。
- 從側面碰到敵人、掉入坑洞或生命歸零，都會失去一條命或直接進入遊戲結束。
- 碰到旗桿即可過關，並依剩餘時間加分。

## 本機執行

本專案不需要安裝額外套件，只要透過 HTTP 伺服器開啟即可：

```bash
cd AS2_source
python -m http.server 8000
```

接著開啟 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。
